I am a Full-Stack Developer, DevOps Engineer, and Security Researcher who thrives at the intersection of performance and privacy. I don't just write code; I design highly scalable, secure, and resilient ecosystems. My philosophy is simple: **Software should be fast, infrastructure should be invisible, and security should be absolute.**

Whether it's deploying serverless edge nodes, reverse-engineering network protocols, writing low-level Rust applications, or managing custom PvP server networks, I build solutions that scale globally.

## 🛠️ What I Build (End-to-End Solutions)

### 🌐 Web & Serverless Ecosystems
I build web applications that load in milliseconds and scale infinitely without managing traditional servers.
* **Complex Architectures:** E-Commerce platforms, SaaS dashboards, and WebRTC streaming applications.
* **Edge Computing:** Utilizing Cloudflare Workers and D1 (SQLite) for ultra-low latency serverless APIs.
* **Modern UI/UX:** Dark-mode, high-contrast, minimalist interfaces inspired by Apple design guidelines.

### 📱 Multi-Platform Application Development
Native-feeling applications built from unified codebases.
* **Mobile & Desktop:** Custom iOS/Android apps and native desktop tools (accounting, media, VPN clients).
* **Browser Extensions:** Advanced Manifest V3 extensions for web scraping, automation, and media downloading.
* **Native Tooling:** Leveraging Tauri (Rust) and Electron for deep OS integration (like custom window controls).

### 🔐 Cyber Security & Network Infrastructure
Security isn't a feature; it's the foundation of everything I write.
* **Offensive Security:** Penetration testing, vulnerability discovery (SQLi, XSS, CSRF), and protocol analysis.
* **Defensive Architecture:** Server hardening, DDoS mitigation, fail-safes, and advanced traffic obfuscation.
* **Proxy Engineering:** Architecting Xray, VLESS, Trojan, and WireGuard tunneling systems.

### 🎮 Game Development (Minecraft)
I run, optimize, and write software for competitive gaming environments.
* **Client-Side:** Writing custom Java 8 / Forge PvP clients (Minecraft 1.8.9) with OpenGL shaders.
* **Server-Side:** Custom Spigot/Paper plugins, economy systems, and BedWars/BuildFFA mechanics.
* **Network Infrastructure:** BungeeCord/Velocity proxy routing and aggressive JVM tuning for 100+ player concurrency.

### ⚙️ DevOps & Cloud Automation
If I have to do it twice, I write a script for it.
* **CI/CD Pipelines:** Fully automated GitHub Actions for building, testing, and deploying across Linux, Windows, and Android.
* **Containerization:** Dockerizing complex architectures for guaranteed cross-environment compatibility.
